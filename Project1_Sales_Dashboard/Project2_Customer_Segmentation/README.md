# Project 2: Customer Segmentation using RFM Analysis and K-Means Clustering

## Project Overview
This project performs customer segmentation using RFM (Recency, Frequency, Monetary) Analysis and K-Means Clustering. The objective is to group customers based on their purchasing behavior and provide business recommendations to improve customer retention and marketing strategies.

## Objectives
- Analyze customer purchasing behavior.
- Calculate Recency, Frequency, and Monetary (RFM) metrics.
- Segment customers using K-Means Clustering.
- Visualize customer segments.
- Generate business insights and marketing recommendations.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- VS Code

## Project Files
- `project2_rfm.ipynb` – Python notebook
- `Sample - Superstore.csv` – Dataset
- `Customer_Segments.csv` – Output dataset
- `Project2_Report.pdf` – Final project report

## Analysis Performed
- Data Cleaning and Preprocessing
- RFM Analysis
- Data Standardization
- Elbow Method
- K-Means Clustering
- Customer Segment Analysis
- Data Visualization
- Business Recommendations

## Key Findings
- Customers were grouped into distinct segments based on their purchasing behavior.
- High-value customers were identified for loyalty programs.
- At-risk customers were identified for re-engagement campaigns.
- The analysis helps businesses implement targeted marketing strategies and improve customer retention.

## Conclusion
This project demonstrates how RFM Analysis and K-Means Clustering can be used to understand customer behavior and support data-driven marketing decisions.
