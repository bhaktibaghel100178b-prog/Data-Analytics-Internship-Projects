# Project 3: A/B Testing Analysis

## Project Overview
This project analyzes the effectiveness of two marketing campaigns (Ad and PSA) using A/B Testing techniques. The analysis determines whether there is a statistically significant difference in conversion rates between the two groups.

## Objectives
- Compare conversion rates between Ad and PSA groups.
- Perform statistical hypothesis testing.
- Calculate confidence intervals.
- Measure effect size.
- Conduct power analysis.
- Provide business recommendations based on the results.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Statsmodels
- VS Code

## Project Files
- `project3_ab_testing.ipynb` – Python notebook
- `marketing_AB.csv` – Dataset
- `Project3_Report.pdf` – Final report

## Analysis Performed
- Data Exploration
- Conversion Rate Analysis
- Chi-Square Test
- Two-Proportion Z-Test
- Confidence Interval Calculation
- Effect Size Analysis
- Power Analysis
- Data Visualization

## Conclusion
The project uses statistical analysis to evaluate whether the new marketing strategy performs significantly better than the existing one and provides data-driven recommendations for decision-making.
