# Data Analytics Internship Projects

## Overview

This repository contains the projects completed during my Data Analytics Internship. The projects demonstrate practical skills in data visualization, customer analytics, machine learning, and statistical analysis using Tableau and Python.


## Project 1: Sales Dashboard (Tableau)

### Objective
Analyze Superstore sales data and build an interactive dashboard to monitor business performance.

### Key Features
- Sales KPI Dashboard
- Regional Analysis
- Category-wise Performance
- Top & Bottom Products
- Sales Forecasting
- Customer Lifetime Value (CLV)

**Tools:** Tableau

---

## Project 2: Customer Segmentation using RFM Analysis

### Objective
Segment customers based on purchasing behavior using RFM Analysis and K-Means Clustering.

### Key Features
- Data Cleaning
- RFM Analysis
- K-Means Clustering
- Customer Segmentation
- Business Recommendations

**Tools:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn


## Project 3: A/B Testing Analysis

### Objective
Evaluate the performance of two marketing campaigns using statistical hypothesis testing.

### Key Features
- Conversion Rate Analysis
- Chi-Square Test
- Two-Proportion Z-Test
- Confidence Intervals
- Effect Size
- Power Analysis
- Business Recommendations

**Tools:** Python, Pandas, SciPy, Statsmodels, Matplotlib, Seaborn
